# Совместимость API

Миграция на Bot Platform v1 выполняется без удаления существующего API библиотеки.
Публичные методы `VoiceRouteClient`, prefix-команды, legacy SSE и cursor stores остаются
совместимыми в пределах линейки `0.x`.

## Режимы транспорта

- `legacy` использует существующие `/api/...` и SSE endpoints;
- `v1` использует `/api/v1/...` и Gateway;
- `auto` сначала проверяет capabilities и выбирает доступный современный транспорт,
  сохраняя legacy fallback.

Появление v1 не меняет смысл существующих `message.seq` и `StreamCheckpoint`.
Следующие позиции хранятся раздельно:

- `message.seq` — последовательность сообщений legacy-канала;
- SSE cursor — позиция legacy-потока;
- Gateway sequence — глобальная позиция Gateway-сессии;
- delivery cursor — позиция durable subscription;
- pagination cursor — непрозрачная позиция страницы REST.

Все cursor, sequence и version значения сохраняются строками. Библиотека не преобразует
их в числа, даже если текущее значение состоит только из цифр.

## Политика изменений

Переход на v1 не требует менять существующий код бота. Новые возможности добавляются
через отдельные типы и transports, а старые методы переключаются на v1 только после
контрактных тестов эквивалентности. Удаление legacy API возможно только в следующей
мажорной версии библиотеки и после объявления сервером даты sunset.
