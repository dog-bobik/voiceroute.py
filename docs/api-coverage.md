# Покрытие API VoiceRoute

Покрытие кода тестами и покрытие API — разные метрики. Процент из `pytest-cov`
показывает, сколько веток Python-кода выполнили тесты. Эта матрица показывает, какие
bot-compatible ресурсы [VoiceRoute](https://voiceroute.cc) представлены публичным API
библиотеки.

В знаменатель не входят пользовательские сессии, пароль, MFA, друзья, личные и
групповые чаты, управление bot applications/installations и создание сообщества: по
предоставленному контракту bot token получает для них `403`. Голос также не считается
реализуемым ресурсом, пока сервер не выдаёт сторонним ботам WebRTC token.

| Домен | Реализовано | Контрактные тесты | Статус |
| --- | --- | --- | --- |
| Текущий бот | профиль и совместимый `/auth/me` | частично | базовый |
| Сообщества | список, одно сообщество | да | базовый |
| Каналы | список доступных каналов | да | базовый |
| События | channel SSE, catch-up, checkpoint | да | готово |
| Application commands | registry, typed options | да | готово |
| Interactions | bot SSE, checkpoint, dispatch, public/ephemeral response | да | готово |
| Сообщения | история, отправка, edit, delete | да | готово |
| Контент сообщений | pins, reactions, search | да | готово |
| Вложения | — | — | следующий домен |
| Треды и форумы | — | — | следующий домен |
| Участники | список, channel visibility, lookup, presence | да | готово |
| Permissions | полный реестр, effective bot set, checks | да | готово |
| Роли | snapshot в Member, без управления | частично | следующий домен |
| Баны, timeout, AutoMod, audit | — | — | запланировано |
| Categories и управление channels | — | — | запланировано |
| Expressions, sounds, soundboard | — | — | запланировано |
| Webhooks | — | — | запланировано |
| Stage и music | — | — | требует отдельного контракта |

Матрица ведётся по доменам, а не одним вводящим в заблуждение процентом. Некоторые
маршруты в реестре являются alias одного обработчика, а отдельные маршруты формально
находятся под `/api/communities/:id/...`, но требуют внешнего сервиса или недоступного
ботам транспорта. Числовой процент появится после машиночитаемого OpenAPI со
стабильными operation ID и признаками bot compatibility.
