# Политика безопасности

Не публикуйте сведения об уязвимости в открытом issue до согласования исправления.
Свяжитесь с владельцем репозитория через приватный канал GitHub.

Никогда не прикладывайте к отчёту действующие bot token, cookie, пароль,
recovery code или полный секретный URL вебхука. Перед отправкой логов удалите из
них все секреты.

Поддерживаемые версии будут перечислены здесь после первого стабильного релиза.
